Oracle-offset arm of the MNAR masked backtest (`bc/python_models/statistical/backtests/mnar_masked.py`) run against four registered synthetic mask designs, geometry/trajectory variant, smoke budget (`SMOKE_BUDGET=1000`, 50 draws × 50 tune × 2 chains), seed 20260610. `w_class_intensity` is the harness's original design (class × salted-game-hash-bucket intensity); `covariate_joint`, `scorer_blocked`, `era_graded` are the three robustness designs added for referee major 2. The offset applied in every row is the design's own oracle (see "oracle form"), evaluated per `evaluate_offset_arm` against `THRESHOLDS` (`focal_relative_reduction_min=0.25`).

| design | oracle form | focal share error (uncorrected → offset) | relative reduction | TV to truth (uncorrected → offset) | verdict |
|---|---|---:|---:|---:|---|
| w_class_intensity | exact: `logit(clip(w_class·mean_intensity))`, the true generative form | 0.1067 → 0.0005 | 0.995 | 0.1067 → 0.0096 | correction ≈ exact |
| era_graded | class-marginal, realized empirically; true selection depends on class × season, and season is not a covariate the geometry model conditions on, so the marginal-offset assumption (selection ⊥ model covariates \| class) still holds | 0.1008 → 0.0042 | 0.958 | 0.1008 → 0.0208 | correction ≈ exact, matching w_class_intensity |
| covariate_joint | class-marginal, realized empirically; true selection depends on class × batter_hand, and batter_hand IS a fixed effect the geometry model conditions on, so the marginal-offset assumption is genuinely violated — this oracle is deliberately misspecified relative to the true (class × covariate) selection function, not a bug | 0.1365 → 0.0632 | 0.537 | 0.1365 → 0.0651 | correction clearly partial — cuts the error roughly in half, well short of the ≈exact designs |
| scorer_blocked | class-marginal, realized empirically; true selection depends only on game block membership, independent of class, so the per-class marginal offset comes out ≈ flat across classes and the reweight's per-event renormalization makes a flat offset ≈ a no-op | 0.0249 → 0.0245 | 0.015 | 0.0249 → 0.0245 | correction ≈ no-op — and unnecessary: the uncorrected bias is already small because class-independent selection is close to MAR for the marginal class shares |

Every run's `overall_pass` / `offset.pass` gate itself reads `False` for all four designs at this smoke budget — that is a sampler-budget artifact (`ess_bulk_min` 20–47 vs the gate's 100 floor at 100 total post-warmup draws), not a correction failure; `rhat_max` stayed ≤ 1.12 everywhere. `scorer_blocked`'s `offset.criteria.focal_share_error_reduced` reads `False` for a different, correct reason: the 0.958/0.995/0.537 relative reductions above clear the 0.25 floor, but scorer_blocked's 0.015 does not — there being (almost) nothing to correct is the expected outcome for that design, not a defect in the offset mechanism.

Absolute TV is not comparable across designs (each mask realizes a different uncorrected bias scale); relative reduction is the right comparison axis, and on that axis the predicted ordering (w_class_intensity ≈ era_graded > covariate_joint ≫ scorer_blocked) holds cleanly across all four runs.

Design-realization checks, from each run's `mask_summary.json`: `covariate_joint` resolved covariate column `batter_hand` (values `{"L", "R"}` in production), realized an overall masked share of 0.7120 (target `overall_masked_target=0.70`), and realized `masked_share_by_covariate_level` 0.490 (level 0.70) vs 0.872 (level 1.30) — the class × covariate interaction is present, not just a marginal level shift. `_covariate_bucket` assigns the two hand values to different buckets by sorting the distinct values and using `rank % 2`, not a salted hash into 2 buckets — a hash split was tried first and silently degenerated on this exact column (both real `batter_hand` values landed in the same hash bucket, leaving only the ~0.07% null rows in the other bucket, which is what a first pass of these results showed before the fix). `scorer_blocked` blocked 58,561 / 79,822 maskable games (0.734), matching the design's target `overall_masked_target / block_probability = 0.70 / 0.95 ≈ 0.737`. `era_graded` realized the same per-class `class_mask_probabilities` as `w_class_intensity` (0.659 non-focal / 0.754 GroundBall) by construction — only the intensity-bucket assignment mechanism differs (season quantile vs salted game hash).
