# ML pipeline (Keras 3 + PyTorch + MLflow)

- `KERAS_BACKEND=torch` is set once in `ml/__init__.py`. Don't re-set it elsewhere.
- `TargetSpec` (`features.py`) carries `kind ∈ {multiclass, binary, regression}`. `model_factory._make_outputs_layer` dispatches softmax / sigmoid / linear heads off `kind`. Per-target wrappers stay thin: `model_<target>.py`, `scripts/train_<target>.py`, `predictions_<target>.py`.
- `model_factory.build_model` (single-head) and `build_pretrain_model` (multi-head pretext) both call the shared `_build_backbone(layout, vocab_sizes, ...) -> _Backbone` extractor and only differ in how they attach heads.
- `FeatureLayout.embedding_groups` (`features.py`) declares shared-Embedding groups. Each group `(name, (col1, col2, …))` builds ONE Embedding layer (`embed_<group_name>`) and routes every member column through it; the vocab union spans all members. Ungrouped high-card cols keep their own `embed_<col>`. `_build_backbone` reuses the group Embedding per member column and applies `SpatialDropout1D(0.1)` after each lookup, then a `LayerNormalization` at the trunk concat. `set_pretrained_embeddings(..., embedding_groups=...)` honors the group layout when copying rows from a `kind="pretrain"` artifact: it looks up the right `embed_<unit>` layer and copies entity-keyed rows so per-target consumers receive only the players that appear in their own per-column vocabulary.
- Pretrain heads always split into `Dense(name=f"{head}_logits", activation=None)` + `Activation(name=head)` so the pre-softmax tensor is addressable by name (the residual-decomposition pretrain needs it). `build_pretrain_model(..., offset_inputs: Mapping[str, keras.KerasTensor] | None)` injects an additive `keras.Input(shape=(num_classes,), name=f"offset_{head}")` per head when supplied: `Add([dense_logits, offset_input]) → Softmax`. Stage 2 of the residual pretrain passes one offset per head loaded from the stage-1 cache. Loss type is selectable via `build_pretrain_model(..., loss_type="focal"|"cross_entropy", focal_gamma=...)`; training driver reads `BC_PRETRAIN_LOSS` / `BC_PRETRAIN_FOCAL_GAMMA`.
- `PretrainModel` (`model_factory.py`) is a `keras.Model` subclass with Kendall-Gal uncertainty weighting (per-head `log_sigma` trainable variable: `total = 0.5 * exp(-log_sigma) * head_loss + 0.5 * log_sigma`) plus split optimizers — `trunk_optimizer` (Adam, base 1e-3) for cross / deep / heads, `embed_optimizer` (Adam, base 5e-3) for `embed_*` + `log_sigma_*`. Both schedules linearly warm up 5 % of total steps then `CosineDecay(alpha=0.1)`. `configure_pretrain(...)` rebinds optimizers + losses; call it after any freeze/unfreeze. The custom `train_step` does standard torch autograd then splits gradients by variable path.
- Training is offline. Run `scripts/train_<name>.py` to produce the artifact JSON at `bc/python_models/ml/artifacts/<name>.json`.
- The `predictions_<target>.py` `@model` gates on `artifact_exists(target)`, so a fresh prod plan skips untrained targets cleanly. Don't break this gate.
- Predictions stream via DuckDB Arrow `to_batches` with `_BATCH_ROWS=500_000`.
- ML deps live in the `ml` uv group (`apache-hamilton`, `mlflow`, `keras`, `torch`, `scikit-learn`). Mutually exclusive with the `bsl` group — don't try to install both into the same env.
