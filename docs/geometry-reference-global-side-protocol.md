# Corrected global-side reference protocol

Defined September 11, 2026 after the recorded-angle comparison. This protocol applies only to subsequent runs against the corrected geometry-v2-global-side dataset. It is a development comparison on the already-inspected primary TEST partition, not untouched confirmation or evidence of historical MNAR identification.

- Targets: global location side mapped from directly recorded general location, and trajectory; observed classes only, positive training weight, one event per target. Global side retains the explicit coarse All category as well as Left/Middle/Right; All does not specify a precise direction. Fielder-derived side and ambiguous local-angle Default values are excluded from truth. Require the geometry-v2-global-side contract before side extraction. The side population changes from the legacy angle benchmark; regenerate every comparator on the corrected population. Retain the Bunt remapping and primary TRAIN/TEST game split. No VALIDATE labels are used.
- Fit budget: 100,000 TRAIN events per target, selected by SHA-256 of event key plus fixed seed, with event key as tie-breaker. Fit label and feature vocabularies on that selected TRAIN frame only.
- Model: additive categorical logit, with global class intercept and terms for decade, result family, base state, outs, alignment regime, and batter hand. Intercepts have zero-sum Normal scale 1.5; feature effects have zero sums across both levels and classes and Normal scale 0.5. This is a regularized Bayesian reference in the existing geometry model family, with an explicit era term and removal of redundant additive parameter directions; it is not an exact refit of an existing artifact.
- Exclude all pretrained representations, deep proposals, propensity estimates, and handler posterior inputs. Preserve missing recorded features as explicit categories; unseen TEST categories contribute the zero centered feature effect.
- Fit the multinomial likelihood to counts aggregated over identical feature vectors. This has the same parameter-dependent likelihood as fitting the selected individual categorical observations. Conditional event independence remains a modeling assumption, including within games.
- NUTS budget: four chains, 1,000 warmup and 1,000 saved draws per chain, target acceptance 0.95, maximum tree depth 12, seed 20260911. Smoke: 3,000 TRAIN events, up to 5,000 TEST events, two chains and 50 warmup/50 saved draws. Prior predictive checks precede posterior sampling. Sampling repair may depend on diagnostics, never on TEST performance.
- Predict using the posterior mean of softmax probabilities, not softmax of mean coefficients. Score every original TEST event for each target; preserve event IDs, truth, and aligned probability vectors in Parquet.
- Comparators: add-one marginal and decade × result baseline on exactly the model's selected TRAIN events; additionally the original full-TRAIN decade × result baseline. No TEST labels enter these fits.
- Report log loss, multiclass Brier, classwise 15-bin ECE, reliability bins, and the pre-1988 observed-only slice. Paired 95% intervals resample TEST games 500 times, event-weighted with fitted TRAIN models fixed. They do not integrate training-sample uncertainty.
- A useful matched-budget result requires positive lower confidence bounds for both log-loss and Brier improvement over the matched contextual baseline, ECE ≤ 0.05, no observed pre-1988 log-loss regression, R-hat ≤ 1.05, bulk and tail ESS ≥ 100, and zero divergences. Report the full-data comparator separately even if it changes the practical decision.
- Freeze source extracts, selected training rows, full-TRAIN baseline counts, encoders, code hashes, package versions, priors, posterior draws, diagnostics, and scores under a new isolated research artifact directory. Never overwrite an existing run. No publication or production database writes.

The reference measures predictive performance on recorded events. Source/scorer effects, selection bias, causal effect identification, missing games, and historical transport are outside this experiment. A favorable result advances a candidate to historical masking tests; it does not authorize publication.

Implementation references: [PyMC ZeroSumNormal](https://www.pymc.io/projects/docs/en/v5.7.0/api/distributions/generated/pymc.ZeroSumNormal.html) supports constraints across multiple axes; [PyMC Multinomial](https://www.pymc.io/projects/docs/en/v5.24.0/api/distributions/generated/pymc.Multinomial.html) supplies the aggregated categorical likelihood.
