# Trajectory era-by-result interaction protocol

Frozen before fitting or scoring on September 11, 2026. This is a narrow development comparison on the previously inspected TEST partition. It is not untouched confirmation, historical transport evidence, MNAR identification, or publication evidence.

- Estimand: the recorded trajectory class distribution among events with a recorded trajectory label and positive training weight. The five classes use the frozen geometry reference Bunt remapping.
- Frozen population: reuse byte-for-byte `train.parquet`, `test.parquet`, and `full_train_counts.parquet` from `artifacts/statistical/backtests/geometry_reference/20260911-full-v1/trajectory/data`, plus its aligned additive `test_predictions.parquet`. The selected TRAIN population has 100,000 events and the TEST population has 922,812 events. Record and verify every source digest before fitting. No VALIDATE data are read.
- Scientific contrast: replace the additive decade and result-family effects with one observed TRAIN decade-by-result-family categorical factor. Retain base state, outs, alignment regime, and batter hand as additive categorical effects. An interaction level absent from selected TRAIN contributes zero on TEST.
- Priors and constraints: the class intercept is zero-sum Normal with scale 1.5. Every feature matrix is zero-sum across feature levels and classes with scale 0.5. The likelihood is multinomial over counts aggregated by identical feature vectors. No deep representation, propensity, handler posterior, or other learned covariate is used.
- Sampling: seed 20260911; nutpie NUTS; four chains; 1,000 warmup and 1,000 saved draws per chain; target acceptance 0.95; maximum tree depth 12. The real-data smoke uses a deterministic 3,000-row subset of selected TRAIN and the first 5,000 event-key-ordered TEST rows, with two chains and 50 warmup plus 50 saved draws. Smoke scores may diagnose numerical or alignment failures only and cannot change the scientific specification.
- Prediction: posterior mean of draw-level softmax probabilities for every TEST event, preserving event order. Fit class and factor vocabularies only on the passed TRAIN frame.
- Comparison: require exact event-key, game, season, truth, class-label, selected-TRAIN digest, and TEST digest agreement before pairing the new interaction probabilities with the saved additive probabilities. Retain the saved matched-budget marginal, matched-budget decade-by-result, and full-TRAIN decade-by-result baselines as descriptive comparators.
- Metrics: log loss, multiclass Brier score, classwise 15-bin ECE, and the pre-1988 recorded-only slice. Compute paired 95% intervals from 500 TEST-game bootstrap repetitions with all fits fixed. For the direct scientific contrast, positive gain means the interaction model has lower loss than the additive model.
- Interpretation: the direct paired contrast isolates the feature specification within this frozen selected sample, subject to posterior Monte Carlo error from separate fits. Sparse decade-by-result levels can pool only through the fixed Normal prior and zero-sum constraint. A favorable result supports a missing-interaction hypothesis on recorded TEST events only.
- Artifacts: refuse overwrite; copy the frozen source inputs and this protocol; save run configuration, package and implementation hashes, train-only encoders, prior check, posterior, sampling log, diagnostics, aligned probabilities, metrics, and an artifact digest inventory.

The reused geometry 0.4 snapshot predates the corrected global location-side population. That correction does not alter this trajectory population, and this artifact remains research-only rather than evidence for the corrected production pipeline.
